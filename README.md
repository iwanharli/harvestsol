# harvestsol

CropFarm: game farming pixel art ala Harvest Moon, dibangun dengan Phaser 4 + TypeScript + Vite.

Saat ini fase 1 (prototipe tanpa uang sungguhan). Kode game ada di [`game/`](game/), lihat [`game/README.md`](game/README.md) untuk cara menjalankan dan kontrol.

```bash
cd game
./run.sh
```
